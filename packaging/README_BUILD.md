# OffShore - Build and Installer Guide

This document explains how to build a Windows executable and an installer for the OffShore project.

Prerequisites (Windows):

- Python 3.10+ installed and available as `py` or `python`.
- `pyinstaller` installed (`py -m pip install pyinstaller`).
- `Inno Setup` (for creating .exe installer). Download from: <https://jrsoftware.org/isinfo.php>
- Optional: run in an elevated PowerShell if writing to Program Files locations.

1) Install runtime dependencies

```powershell
py -m pip install -r requirements.txt
py -m pip install pyinstaller
```

1) Build with PyInstaller (one-folder, recommended for Streamlit apps)

```powershell
# from repository root
.\packaging\build_exe.ps1
# or
packaging\build_exe.bat
```

To build a single-file executable (larger, can have startup issues for GUI/web apps), run:

```powershell
.\packaging\build_exe.ps1 -OneFile
```

By default the build hides the console window (release build, matching what
customers should see). If you need a visible console for debugging, add
`-Console`:

```powershell
.\packaging\build_exe.ps1 -Console
```

Since the release build has no console, startup errors are not printed to a
terminal. `launcher.py` writes them to `logs\launcher.log` next to the exe
and also pops up a native Windows message box on fatal failures, so end
users always get some feedback instead of the app silently doing nothing.
The Streamlit app itself continues to log to `logs\animation.log` regardless
of the console setting.

Notes:

- The build script adds `assets`, `modules`, `planner`, `viz`, `LICENSE.txt` and `THIRD_PARTY_LICENSES.md` into the bundle. Adjust `--add-data` flags in `packaging\build_exe.ps1` as necessary.
- Streamlit apps often work better packaged as a folder (`--onedir`) rather than `--onefile` due to static assets and web server behaviour.

1) Create an installer with Inno Setup

- Open `packaging\installer.iss` in Inno Setup and compile (File → Compile). It expects the PyInstaller output layout in `dist\OffShoreMentor`.

1) Running the app from installer

- Installer will create a Start Menu shortcut and install files to `%ProgramFiles%\OffShoreMentor` by default.
- The entry exe is `OffShoreMentor.exe` (generated by PyInstaller). Running it should start the bundled Streamlit app. If the app fails to launch directly, run `OffShoreMentor.exe` from a command prompt to see logs.

Code signing (optional, requires a purchased certificate)

Without a code-signing certificate, Windows SmartScreen will warn buyers with
an "Unknown publisher" prompt the first time they run `OffShoreMentor.exe` or
the installer. To remove that warning:

1) Buy a code-signing certificate (OV or EV) from a Certificate Authority
   (e.g. DigiCert, Sectigo, SSL.com). This requires verifying your
   business/legal identity with the CA — it cannot be automated here.
2) Install the Windows SDK (provides `signtool.exe`) so it is on `PATH`.
3) Sign the built .exe by passing your certificate to the build script:

   ```powershell
   .\packaging\build_exe.ps1 -CertPath "C:\path\to\cert.pfx" -CertPassword (Read-Host -AsSecureString)
   ```

   This signs `dist\OffShoreMentor\OffShoreMentor.exe` (or the single-file
   exe with `-OneFile`) using SHA-256 and an RFC3161 timestamp, so the
   signature stays valid after the certificate expires.
4) To also sign the Inno Setup installer output, configure a named
   "Sign Tool" in the Inno Setup Compiler (Tools > Configure Sign Tools)
   pointing at `signtool.exe sign /f cert.pfx /p PASSWORD /fd SHA256 /tr
   http://timestamp.digicert.com /td SHA256 $f`, then uncomment
   `SignTool=mycert` in `packaging\installer.iss` (see the comment there for
   the equivalent one-off `ISCC.exe /S...` command-line form).

Troubleshooting

- If Streamlit cannot bind to a port, use `--server.port` option or set env var `STREAMLIT_SERVER_PORT`.
- If static assets (icons, images) are missing, ensure `--add-data` in the build script includes their folders.
- For more reliable packaging of complex web apps, consider shipping a small launcher `.exe` that runs `python -m streamlit run streamlit_app.py` using the embedded Python instead of trying to bundle the Streamlit server into a single exe.
