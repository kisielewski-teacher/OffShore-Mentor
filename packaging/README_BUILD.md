OffShore - Build and Installer Guide

This document explains how to build a Windows executable and an installer for the OffShore project.

Prerequisites (Windows):
- Python 3.10+ installed and available as `py` or `python`.
- `pyinstaller` installed (`py -m pip install pyinstaller`).
- `Inno Setup` (for creating .exe installer). Download from: https://jrsoftware.org/isinfo.php
- Optional: run in an elevated PowerShell if writing to Program Files locations.

1) Install runtime dependencies

```powershell
py -m pip install -r requirements.txt
py -m pip install pyinstaller
```

2) Build with PyInstaller (one-folder, recommended for Streamlit apps)

```powershell
# from repository root
.\packaging\build_exe.ps1
# or
packaging\build_exe.bat
```

To build a single-file executable (larger, can have startup issues for GUI/web apps), run:

```powershell
.\packaging\build_exe.ps1 -OneFile
```

Notes:
- The build script adds `assets`, `modules`, `planner`, `viz`, `Readme` and `Readme_texts` into the bundle. Adjust `--add-data` flags in `packaging\build_exe.ps1` as necessary.
- Streamlit apps often work better packaged as a folder (`--onedir`) rather than `--onefile` due to static assets and web server behaviour.

3) Create an installer with Inno Setup

- Open `packaging\installer.iss` in Inno Setup and compile (File → Compile). It expects the PyInstaller output layout in `dist\OffShoreMentor`.

4) Running the app from installer

- Installer will create a Start Menu shortcut and install files to `%ProgramFiles%\OffShoreMentor` by default.
- The entry exe is `OffShoreMentor.exe` (generated by PyInstaller). Running it should start the bundled Streamlit app. If the app fails to launch directly, run `OffShoreMentor.exe` from a command prompt to see logs.

Troubleshooting

- If Streamlit cannot bind to a port, use `--server.port` option or set env var `STREAMLIT_SERVER_PORT`.
- If static assets (icons, images) are missing, ensure `--add-data` in the build script includes their folders.
- For more reliable packaging of complex web apps, consider shipping a small launcher `.exe` that runs `python -m streamlit run streamlit_app.py` using the embedded Python instead of trying to bundle the Streamlit server into a single exe.

If you want, I can:
- Update `packaging\build_exe.ps1` to include additional folders/files you require.
- Create a small launcher script (launcher.py) that configures environment variables and launches Streamlit; include it in the build and set it as the PyInstaller entrypoint.
- Automate Inno Setup compilation if you have ISCC.exe installed on CI/machine.
