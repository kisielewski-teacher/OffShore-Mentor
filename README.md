Offshore Mentor

Prosty symulator planowania napraw turbin offshore.

Uruchomienie:

1. Zainstaluj wymagania:

```powershell
python -m pip install -r requirements.txt
```

2. Uruchom aplikację Streamlit:

```powershell
streamlit run streamlit_app.py
```

Uwagi:
- `ruff` został użyty do sformatowania kodu.
- Jeżeli brakuje `pydeck` lub innych zależności, zainstaluj je przez `pip`.
