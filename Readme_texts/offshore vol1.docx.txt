TECHNICZNE PODSUMOWANIE PROJEKTU (dla nowego modelu AI)

1. Cel skryptu / aplikacji

Aplikacja to interaktywny symulator serwisowania farm wiatrowych offshore, napisany w Streamlit.
Jej zadania:

generować losowe usterki turbin offshore (z realistycznymi współrzędnymi na morzu),

generować okna pogodowe i dostępne statki,

planować naprawy z uwzględnieniem pogody, priorytetów, czasu tranzytu i kosztów,

wyświetlać KPI, mapę turbin + portu, harmonogram Gantta oraz tabelę wyników,

umożliwiać użytkownikowi sterowanie parametrami symulacji.

2. Aktualny stos technologiczny

Projekt korzysta z:

Python 3.x

Streamlit – UI i wizualizacja mapy

pandas – struktury danych

altair – wykres Gantta

moduły własne:

data.generate – generowanie danych wejściowych

planner.plan – logika planowania napraw

viz.gantt (opcjonalnie) – niestandardowy wykres Gantta

Brak zewnętrznych API, Selenium, requests itp.

import random from planner.plan import Fault, Window, Vessel def gen_faults(n=30): faults = [] for i in range(n): # Turbiny ~20 km na zachód od Ustki, zawsze na morzu lat = random.uniform(54.65, 54.75) lon = random.uniform(16.40, 16.70) faults.append(Fault( fault_id=f"F-{i:03d}", turbine_id=f"T-{random.randint(1,50):03d}", reported_h=random.randint(0, 7*24 - 24), repair_hours=random.choice([4, 6, 8, 12]), priority=random.choice([1, 2, 3]), lat=lat, lon=lon )) return faults def gen_windows(): windows = [] t = 0 while t < 7 * 24: dur = random.choice([6, 8, 12, 24]) windows.append(Window( win_id=f"W-{len(windows):03d}", start=t, end=min(t + dur, 7 * 24), hs_m=round(random.uniform(0.5, 2.5), 1), wind_ms=round(random.uniform(4, 18), 1) )) t += dur return windows def gen_vessels(): return [ Vessel("V-1", "CTV-Alpha", teams=2, speed_kn=20, day_cost_pln=3500.0), Vessel("V-2", "CTV-Beta", teams=1, speed_kn=18, day_cost_pln=3200.0), ]

4. Rozwiązane problemy (nie powtarzać!)

❌ Błędy niedomkniętych stringów ("---) → naprawione

❌ Turbiny generowane na lądzie → poprawione zakresy współrzędnych

❌ Mapa pokazywała punkty w złych miejscach → ustalono stabilny obszar na morzu

❌ Problemy z importem Gantta → dodano fallback

❌ Niespójne współrzędne portu → ustalone na stałe (Ustka)

5. Zadanie do wykonania jako następne

Dodać wizualizację trasy statku (linia port → turbina) na mapie.

To będzie kolejny moduł, który:

po wybraniu turbiny narysuje linię od portu do turbiny,

obliczy długość trasy,

wyświetli ją na mapie (np. przez pydeck lub st.pydeck_chart).
