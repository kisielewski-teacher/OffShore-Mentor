3) Funkcja celu i ograniczenia

Funkcja celu (MVP):



gdzie downtime = łączny czas napraw (z uwzględnieniem oczekiwania na okno pogodowe), a cost = koszt dobowy statku × szacowana liczba dni serwisu.

Ograniczenia (konfigurowalne):

Usterka wykonywana tylko w oknie pogodowym spełniającym progi (np. Hs, wiatr).

Ekipa statku może być przydzielona do jednej naprawy w danym czasie.

Początek naprawy ≥ czas zgłoszenia usterki.

(Opcj.) Czas dojazdu port → turbina (zależny od prędkości kn i odległości) oraz okna „tranzytowe”.

Warto zaznaczyć, że progi pogodowe dla operacji CTV/Crew Transfer są różne dla operatorów i jednostek; w aplikacji stosujemy ustawienia użytkownika (domyślnie podkład wartości edukacyjnych). Dopuszczenie konfiguracji jest też spójne z „wizjonerskim” charakterem MEWy. [bing.com]

5) Algorytm (heurystyka „priority-first with feasible window”)

Kroki:

Posortuj usterki wg (priority, reported_h).

Dla każdej usterki znajdź pierwsze dostępne okno spełniające progi pogodowe i kończące się ≥ (czas zgłoszenia + czas naprawy).

Przydziel pierwszy wolny statek (teams ≥ 1; brak kolizji w slotach czasu).

Zaktualizuj plan (zajętość czasu × statek), wylicz koszt (proporcjonalnie do czasu/dni).

Zapisz harmonogram; gdy brak zasobów lub okien — oznacz „niezaplanowane”.

Rozszerzenia (iteracje późniejsze):

Wstawianie „tranzytu” port→turbina i back (czas zależny od odległości).

Local search (np. zmiana kolejności swap / 2-opt), multi-kryterialne ważenie koszt vs. downtime.

Priorytety dynamiczne (podniesienie dla długotrwałych usterek).

Możliwość pracy z historycznymi oknami pogodowymi (MJO, reanaliza) — zwiększa wiarygodność symulacji.

6.1. Logika planowania (Python)

Python

# file: planner/plan.py

from dataclasses import dataclass

from typing import List, Tuple, Dict



@dataclass

class Fault:

fault_id: str

turbine_id: str

reported_h: int

repair_hours: int

priority: int



@dataclass

class Window:

win_id: str

start: int

end: int

hs_m: float

wind_ms: float



@dataclass

class Vessel:

vessel_id: str

name: str

teams: int

speed_kn: float

day_cost_pln: float



def feasible(w: Window, hs_thr: float, wind_thr: float) -> bool:

return (w.hs_m <= hs_thr) and (w.wind_ms <= wind_thr)



def plan_repairs(faults: List[Fault], windows: List[Window], vessels: List[Vessel],

hs_thr: float = 1.5, wind_thr: float = 15.0) -> Tuple[List[Dict], float]:

# sort usterki

faults = sorted(faults, key=lambda f: (f.priority, f.reported_h))

horizon = max([w.end for w in windows]) if windows else 7*24

usage = {v.vessel_id: [0]*horizon for v in vessels} # 0=free, 1=busy

schedule, cost = [], 0.0



for f in faults:

assigned = False

for w in windows:

if not feasible(w, hs_thr, wind_thr): 

continue

if w.end - w.start < f.repair_hours: 

continue

if w.end <= f.reported_h: 

continue

start = max(w.start, f.reported_h)

end = start + f.repair_hours

if end > w.end:

continue

# szukaj wolnego statku

for v in vessels:

if all(usage[v.vessel_id][h] == 0 for h in range(start, end)):

# zajmij sloty

for h in range(start, end): usage[v.vessel_id][h] = 1

# koszt (uproszczenie): liczba dni serwisu * koszt dobowy

days = (f.repair_hours // 8) + 1

c = days * v.day_cost_pln

cost += c

schedule.append({

"fault_id": f.fault_id, "turbine_id": f.turbine_id,

"start": start, "end": end, "vessel_id": v.vessel_id,

"vessel_name": v.name, "cost_pln": c, "priority": f.priority

})

assigned = True

break

if assigned: break



if not assigned:

schedule.append({

"fault_id": f.fault_id, "turbine_id": f.turbine_id,

"start": None, "end": None, "vessel_id": None,

"vessel_name": None, "cost_pln": 0.0, "priority": f.priority,

"note": "niezaplanowane (brak okna/zasobu)"

})



return schedule, cost

6.2. Generator syntetycznych danych

# file: data/generate.py

import random

from planner.plan import Fault, Window, Vessel



def gen_faults(n=30):

faults = []

for i in range(n):

faults.append(Fault(

fault_id=f"F-{i:03d}", turbine_id=f"T-{random.randint(1,50):03d}",

reported_h=random.randint(0, 7*24-24),

repair_hours=random.choice([4,6,8,12]),

priority=random.choice([1,2,3])

))

return faults



def gen_windows():

windows, t = [], 0

while t < 7*24:

dur = random.choice([6,8,12,24])

windows.append(Window(

win_id=f"W-{len(windows):03d}", start=t, end=min(t+dur, 7*24),

hs_m=round(random.uniform(0.5, 2.5),1),

wind_ms=round(random.uniform(4, 18),1)

))

t += dur

return windows



def gen_vessels():

return [

Vessel("V-1","CTV-Alpha",teams=2,speed_kn=20,day_cost_pln=3500.0),

Vessel("V-2","CTV-Beta", teams=1,speed_kn=18,day_cost_pln=3200.0),

]

6.3. Prosty UI w Streamlit (Gantt + KPI)

Python

# file: streamlit_app.py

import streamlit as st

import pandas as pd

import altair as alt

from data.generate import gen_faults, gen_windows, gen_vessels

from planner.plan import plan_repairs



st.title("Offshore Mentor – Symulator serwisowania farm wiatrowych")



col1, col2 = st.columns(2)

with col1:

n_faults = st.slider("Liczba usterek", 10, 80, 30)

hs_thr = st.slider("Próg Hs [m]", 0.5, 3.0, 1.5, 0.1)

with col2:

wind_thr = st.slider("Próg wiatru [m/s]", 5.0, 20.0, 15.0, 0.5)

day8h = st.checkbox("Dzień pracy = 8h (szacunek kosztów)", value=True)



faults = gen_faults(n_faults)

windows = gen_windows()

vessels = gen_vessels()



schedule, tot_cost = plan_repairs(faults, windows, vessels, hs_thr=hs_thr, wind_thr=wind_thr)

df = pd.DataFrame(schedule)



st.subheader("KPI")

st.metric("Zaplanowane naprawy", int(df["start"].notna().sum()))

st.metric("Niezaplanowane", int(df["start"].isna().sum()))

st.metric("Szac. koszt [PLN]", f"{tot_cost:,.0f}")



st.subheader("Gantt – harmonogram napraw")

gantt = alt.Chart(df[df["start"].notna()]).mark_bar().encode(

x=alt.X('start:Q', title='Godzina'),

x2='end:Q',

y=alt.Y('fault_id:N', title='Usterka'),

color=alt.Color('vessel_name:N', title='Statek')

).properties(height=400)

st.altair_chart(gantt, use_container_width=True)



st.subheader("Tabela harmonogramu")

st.dataframe(df)
