Instrukcja jeszcze bardziej techniczna

1. W jakim programie i języku został napisany?

Projekt OffShore został napisany w Pythonie (3.10+), z wykorzystaniem środowiska wirtualnego (.venv) i zarządzania pakietami przez pip.
Powód wyboru Pythona:

Duże wsparcie dla analizy danych i uczenia maszynowego.

Łatwość integracji z API i narzędziami do wizualizacji.



✅ 2. Jakie biblioteki i dodatki zostały użyte?

Główne biblioteki:

requests – pobieranie danych z API (np. dane pogodowe, oceanograficzne).

pandas – obróbka danych tabelarycznych (łączenie, agregacja).

numpy – obliczenia numeryczne.

scikit-learn – modelowanie (np. regresja, RandomForest, ew. XGBoost).

joblib – zapis i odczyt modeli.

matplotlib / seaborn / plotly – wizualizacje.

streamlit – dashboard do prezentacji wyników.

python-dotenv – zarządzanie kluczami API.

Dodatki:

Obsługa braków danych (np. interpolacja).

Mechanizm cache dla API.

Harmonizacja czasowa (różne strefy czasowe, tolerancja ±1h).



✅ 3. Główne części projektu

Struktura katalogów:

data/                # Dane wejściowe i wyjściowe

src/

  offshore_fetch.py  # Pobieranie danych oceanograficznych (np. prądy, fale)

  weather_fetch.py   # Pobieranie danych pogodowych

  merge_hourly.py    # Łączenie danych w zbiór godzinowy

  features.py        # Tworzenie cech (średnie, różnice, flagi)

  train.py           # Trening modelu ML

  predict.py         # Generowanie prognozy

  backtest.py        # Testy wsteczne

dashboard/

  offshore_dashboard.py # Streamlit – interfejs użytkownika

scripts/

  run_hourly.sh      # Automatyczne odświeżanie danych i prognoz

  run_train_predict.sh



✅ 4. Jak to zostało scalone?

Pipeline logiczny:
offshore_fetch → weather_fetch → merge_hourly → features → train → predict → dashboard

Dane przechowywane w CSV i modele w Pickle.

Dashboard czyta dane z plików i prezentuje je w czasie rzeczywistym.

Automatyzacja przez skrypty bash lub cron.



✅ 5. Automatyzacja i uruchamianie

run_hourly: pobiera nowe dane i aktualizuje prognozy.

run_train_predict: okresowo trenuje model na nowych danych.

Streamlit dashboard: uruchamiany komendą: 

streamlit run offshore_dashboard.py



✅ 6. Model i cechy

Model: np. RandomForestRegressor lub GradientBoosting.

Cechy: 

Średnie kroczące (np. prędkość wiatru, wysokość fali).

Trendy (zmiany godzinowe).

Pogoda + parametry oceanograficzne (np. prądy, temperatura wody).

Target: np. przewidywanie warunków offshore (wysokość fali, prędkość wiatru) na najbliższe godziny.



✅ 7. Bezpieczeństwo i klucze

Klucze API w .env.

Obsługa błędów (fallback na ostatnie wartości).



✅ 8. Integracja z dodatkowymi źródłami

Możliwość rozszerzenia o dane satelitarne, AIS (ruch statków), dane batymetryczne.
